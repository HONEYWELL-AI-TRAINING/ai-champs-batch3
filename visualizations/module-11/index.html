      The fifth leak

      One big model for everything. A costly model on trivial steps. First fix: route simple steps to smaller models (watch routing overhead). It changes the price of each token rather than the token count, so it is covered in the next card.
      Find it before fixing it: use the trace to see which step carries the tokens. Optimising a step that costs little is effort wasted.

        Part 6 · Best Practices & Wrap-up

        Measure early, count accepted work, and keep a named owner for every workflow. Sort each habit.

        Golden rule: if you cannot trace what an agent did, price what it cost and show what it was worth, you cannot responsibly scale it.
