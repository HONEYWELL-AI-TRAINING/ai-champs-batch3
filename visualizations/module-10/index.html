The model only sees the description and the input shape. Write them for the model.

pseudocode — map to your SDK's real API names
tool get_build_status:
  description: "Status and failing step for a build.
                Read-only. id looks like b-1234."
  inputs:      build_id: string (pattern b-####)
  handler:     return ci_api.status(build_id)

agent = create_agent(
  instructions = "Explain build failures. Use tools;
                  never guess. Say if unsure.",
  tools = [get_build_status])

agent.send("Why did build b-1234 fail?")
  • One tool, one job — narrow, clearly named
  • Describe for the model — say when to use it and what it returns
  • Typed, validated inputs — reject bad arguments in the handler
  • Small, structured output — return what is needed, not a dump
